# WiFi Float

Android 16 / Galaxy S24 Ultra experimental Wi-Fi floating switch using Shizuku.

## Build
GitHub Actions > Build Android APK > Run workflow. Download the artifact when successful.

## Setup
Install and start Shizuku using wireless debugging, grant Shizuku permission in the app, allow draw-over-other-apps permission, and start the floating button.

Tap to toggle Wi-Fi, drag to reposition, long press to stop.

**Experimental:** Shizuku.newProcess is a deprecated API and may not work on newer versions. Wi-Fi toggling and overlays have not been verified on Galaxy S24 Ultra. No APK has yet been successfully built or tested.
